# 📖 Overview

TrustLens AI is a prototype platform designed for the **SEBI Securities Market TechSprint 2026**.

It demonstrates how AI, cryptographic verification, registry validation, and explainable trust scoring can work together to help identify fraudulent communications targeting investors in India's securities markets.

The project focuses on transparency, explainability, and investor protection.

---

# ✨ Key Features

- 🔍 AI-powered communication analysis
- 🛡️ Cryptographic signature verification (conceptual)
- 🏛️ Registry verification workflow
- 📊 Explainable Trust Score Engine
- 🧠 Multi-signal fraud detection
- 📜 Transparent AI explanations (XAI)
- 📈 Analysis history dashboard
- 🏗️ System architecture visualization
- 📱 Responsive modern interface

# ⚠️ Disclaimer

This project is a **prototype** created for the **SEBI Securities Market TechSprint 2026**.

All communications, trust scores, verification outputs, analysis results, registry lookups, and fraud detection signals shown in the application are **simulated** for demonstration purposes.

The application is intended to showcase the proposed workflow and user experience rather than represent a production-ready regulatory platform.
